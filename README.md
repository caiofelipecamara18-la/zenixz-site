# ZENIXZ — site

Site estático pronto para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `images`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. Salve e aguarde o GitHub gerar o endereço.
